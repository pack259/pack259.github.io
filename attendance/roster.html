Enter the roster code

The roster code is in the Config tab of the Pack 259 Attendance Sheet. The leader code does not work here.

Upload the Scoutbook roster

  1. In Scoutbook, download the pack roster as a CSV file (the roster report that lists youth members with their den).
  2. Choose that file here. Only each scout's name and den are sent to the Sheet. Addresses, phone numbers and parent names stay on this device.
  3. Check the changes it lists, then press Update the roster.
